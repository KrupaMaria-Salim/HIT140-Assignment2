# Repository Structure

# Krupa_Task1
Contains the notebook and dataset used for the shooting accuracy analysis.

**Analytic Question:**  
Do teams that reached the knockout stage have a higher average shooting accuracy than teams eliminated in the group stage at the FIFA World Cup 2026?

The analysis includes:
- Data preparation and validation
- Shooting accuracy calculation
- Proportionate stratified random sampling
- Descriptive statistics
- 95% confidence intervals
- Normality testing
- One-sided Welch two-sample t-test
- Data visualisation

Data source: FBref – FIFA World Cup 2026 Squad Shooting Statistics.
